# Electricity Bridge 电费提醒

在网站绑定自己的房间，通过 QQ 接收低余额提醒。支持多人使用，每个人的房间、查询记录和提醒分别保存。

默认每天北京时间 **09:00** 查询，余额 **低于 20 元** 时提醒，每人每天最多一条通知。绑定成功后可以关闭 Windows 助手，无需一直开着电脑。

## 首次绑定

1. 先添加网站绑定区显示的 bot QQ 为好友，申请会自动通过；成为好友后，再登录网站，在“账号设置”绑定自己的 QQ。
2. 点击“绑定电费”，下载并**完整解压** Windows 助手。
3. 在网站点击“生成连接码”，复制 `ELECTRIC-` 开头的完整字符。
4. 打开 `ElectricityAssistant.exe`，填写该网站的 HTTPS 根地址，粘贴连接码，点击“开始连接”。网站地址不要带 `/account/` 等页面路径。
5. 等助手提示准备完成，在 Windows 微信进入**自己的房间**电费余额页，刷新一次。
6. 回网站核对房间、余额和数据更新时间，点击“确认绑定”。
7. 网站显示绑定成功后，用已绑定的 QQ 私聊机器人发送 **电费状态**，检查回复。

可以在网站的“绑定电费／更新电费授权”窗口观看视频教程；全屏后可拖动进度条，按左右方向键或数字小键盘 4／6 快退、快进 5 秒。窗口也提供微信电费页面的复制链接。

无需安装 Python，也不需要自己配置抓包或代理。请保留助手旁的 `_internal` 文件夹，不要只复制 EXE，也不要在压缩包里直接运行。

## 授权失效后续期

当网站显示“授权需更新”，或机器人提醒授权失效时：

1. 在微信重新进入电费余额页；如果出现登录或授权提示，正常完成后确认余额能显示。
2. 回网站点击“更新电费授权” → “生成连接码”。
3. 打开助手，粘贴**新的连接码**，点击“开始连接”。
4. 等准备完成后，在微信刷新余额页。
5. 回网站再次核对房间和余额，点击“确认绑定”。
6. 私聊机器人发送 **电费状态**，确认恢复。

连接码默认 10 分钟有效且只能提交一次，助手单次等待最多 5 分钟。更新失败时不会覆盖原有绑定；已失效的授权需要更新成功后才能恢复查询。一个人的授权失效不会暂停其他人的提醒。

## 查询与提醒

- 私聊 **电费状态** 或 **电费查询**：查看最近一次查询的余额、数据时间和提醒设置，不会立即刷新上游余额。
- 余额低于设定值时，提醒发送给你在网站验证过的 QQ。
- 数据过旧或房间发生变化时，会提示核对；不会把旧数据直接当成欠费。
- 已绑定的用户升级后无需重新绑定。每天的查询时间和提醒阈值以网站、机器人显示为准。

## 常见问题

**网站没有“绑定电费”？** 先完成邮箱验证和 QQ 绑定。如果仍没有入口，请联系该网站的维护者。

**助手没有连接成功？** 确认网站地址正确、连接码未过期，在 Windows 微信重新进入余额页并刷新。超时后重新生成连接码再试。

**显示的房间不对？** 不要点“确认绑定”。先在微信核对当前房间，再重新连接。

**为什么不是最新余额？** 机器人显示最近一次查询结果，上游电表数据也可能延迟更新，请同时查看“数据时间”。

**Windows 提示来源未验证？** 当前助手没有代码签名。请只从本仓库下载，按下载页的 SHA256 校验文件；不需要关闭系统防护。

## 隐私与数据

助手只在你点击“开始连接”后，获取此次电费查询所需的登录会话、客户端标识和房间信息，发送给你填写的网站。请只使用自己信任的网站。

凭据按网站账号加密保存，查询记录和提醒独立处理。不要分享连接码、登录会话或包含这些内容的截图。助手不需要微信密码，不安装根证书，不修改系统代理，不保存原始抓包。上游电费服务当前使用 HTTP，网站接收助手数据使用 HTTPS。

下载包不含个人账号、房间、连接码或预设网站地址。首次填写的网站地址只保存在助手所在目录，连接码不会保存在该配置中。
