# Windows 电费连接助手使用说明

适用 Windows 10/11 x64，无需安装 Python。需要 Windows 微信，以及已经接入本项目接口、向你开放绑定功能的网站。助手不是可脱离网站单独查询所有宿舍的通用客户端。

先添加网站绑定区显示的 bot QQ 为好友，申请会自动通过；成为好友后再进行网站 QQ 绑定。只有绑定 QQ 后才能绑定电费。

网站的“绑定电费／更新电费授权”窗口提供视频教程，全屏后可拖动进度条，左右方向键或数字小键盘 4／6 每次快退、快进 5 秒。

## 下载与首次绑定

1. 从本仓库 Releases 下载 `ElectricityAssistant-windows-x64-v0.2.1.zip`，解压整个文件夹。不要在 ZIP 中直接运行，不要只取出 EXE。
2. 打开 `ElectricityAssistant.exe`。保留同目录的 `_internal` 文件夹。
3. 填写提供连接码的网站根地址，必须以 `https://` 开头，不要带 `/account/` 等页面路径。仅使用自己信任的网站；会话将发送到此地址。
4. 登录该网站，完成邮箱验证并绑定自己的 QQ，在账号设置点击“绑定电费”，生成连接码，将 `ELECTRIC-` 开头的完整字符粘贴到助手。
5. 点“开始连接”。出现准备完成提示后，在微信正常进入本人房间的电费余额页，刷新一次。
6. 助手显示已连接后，回网站核对房间、余额和数据更新时间，点击“确认绑定”。
7. 网站成功后，用已绑定的 QQ 私聊机器人发送“电费状态”，核对余额和设置，然后关闭助手。后续查询和提醒由服务器负责，无需一直开着电脑上的助手。

程序会在解压目录保存 `config.json`，其中只有你填写的网站地址；连接码不保存在该文件。下载包不包含此文件，也不包含任何网站地址、个人账号或登录凭据。提供方也可预先配置可信网站，但其自行分发的包与本仓库的通用包不同。

## 更新授权

当网站或机器人提示授权失效时，先在微信正常进入余额页面；如要求登录或授权，按微信的正常提示完成。回网站点击“更新电费授权” → “生成连接码”，将新码粘贴到助手并开始连接；微信刷新余额页后，回网站核对房间和余额，再点击“确认绑定”。最后发送“电费状态”确认恢复。旧连接码不能重复使用。

每个网站账号使用自己的连接码和房间，不要与别人共用。多用户插件 v0.3.0 兼容本助手，无需更换助手。一个人的授权失效不会影响其他人的查询；续期失败不会覆盖原有绑定。

连接码有效时间由网站决定，配套接口默认为 10 分钟；助手单次等待最多 5 分钟。更新成功不意味着会话永不过期。

## 常见问题

- **网站地址无效**：填写 HTTPS 根地址，不使用示例域名或账号页路径。
- **无法保存网站地址**：解压到自己可写的目录再运行，不要从压缩包或只读目录打开。
- **没有捕获到余额**：确认是 Windows 微信里的余额页，重新进入并刷新；等超时后重试。不同代理或微信版本可能需要提供方排查。
- **请求管理员权限**：本机进程连接组件可能需要权限；确认程序来源后按系统提示操作，不需要手动配置代理或安装根证书。
- **提交失败或码过期**：检查网站地址和网络，重新生成连接码，不要把连接码发给别人。
- **网站没有绑定入口**：需由网站运营者接好后端并开放账号权限；助手本身不会开通账号。
- **Windows 提示来源未验证**：当前程序未做代码签名。核对下载仓库与 SHA256 后再决定是否运行，不需要关闭系统防护。

## 数据范围

只提取本人正常打开 `wx.cdzht.com` 余额页时的 `connect.sid`、User-Agent 和房间。会话用于后续只读余额查询；它是敏感登录凭据，不应公开。HTTPS 不解密，不安装证书，不修改系统代理，不保存原始流量。关闭窗口会终止该助手的连接子进程。

## 校验与第三方材料

在 PowerShell 执行：

```powershell
Get-FileHash -LiteralPath .\ElectricityAssistant-windows-x64-v0.2.1.zip -Algorithm SHA256
```

将结果与同一 Release 的 `SHA256SUMS.txt` 对照。`licenses/` 包含第三方声明，`DEPENDENCIES.json` 列出构建环境版本；Release 另附对应第三方源码材料。不同来源的二进制不要混用校验值。

已验证独立包的依赖、GUI 和配置保存逻辑；关联线上版本完成过真实绑定和模拟失效恢复。当前通用版本新增网站输入框，仍建议部署者完成自己的端到端测试。运营方自然会话过期时间未作保证。
